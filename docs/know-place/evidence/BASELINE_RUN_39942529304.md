## Why this is not a paper reproduction

The prior run is evidence for input selection, reader behaviour and structural gates only. It does not establish the reported 0.96 m crown median. That value requires (i) the source/crown polygon separately from the wider reference box, (ii) the paper's GOFF layer2 SNR/magnitude filters, (iii) AT/SR-to-East/North projection using per-product geometry, (iv) background correction over reference-box pixels outside the crown, and (v) crown-specific magnitude/coherence and size-matched controls.
