## What actually runs

1. `discover_aoi_products.py` validates the requested WKT/date window and builds the exact-product manifest.
2. Reusable per-product workers execute `gunw_reader.py` for GUNW and `goff_reader.py --layer layer2` for GOFF.
3. The aggregator calls `run_export_science_diagnostics.py` for eligible GUNW pixel-stack diagnostics and named-AOI candidate-check policy.
4. The aggregator separately calls `aoi_wide_displacement_screen.py` on retained GOFF exports. This path sets `target_required=false` and does not consume target coordinates.
5. `common_reference.py` and the stage report are run for GUNW time-series eligibility. In target-free mode the common-reference helper exits with `BLOCKED_NO_VALID_IN_AOI_TARGET`; it does not invent a point.
6. `prepare_web_assets.py` creates the interactive viewer and product PNG previews from the retained exported product rasters.

## Main correction priorities

### P0 — make the science visible without overstating it
Publish the AOI screen's `candidate_pair_count.tif`, `persistent_candidate_mask.tif` and directional-coherence raster into the map manifest with layer-specific units/legends. Also publish GUNW pixel-stack LOS velocity and sigma rasters, observed-pair support and contiguous-support masks as distinct layers. Generate PNG previews from those derived outputs, not just raw product bands.

### P0 — repair uncertainty semantics in AOI GOFF screening
The screen uses a range-only reader detection floor to threshold a 2-component range/azimuth residual magnitude. Add per-component variance/covariance support from GOFF exports and use a statistically justified uncertainty-normalized vector statistic. Do not call the existing robust-z threshold a probability.

### P1 — calibrate spatial scale and persistence
The 41-pixel local-mean subtraction can suppress broad motion. Inject compact, medium and broad synthetic signals at multiple amplitudes/directions and measure detection/rejection. Compare multiple GOFF resolution layers. Keep the present two-pair persistence as a review-candidate rule only; do not call it a redundant time series.

### P1 — create an independent target-free GUNW datum strategy
The current common-reference helper requires target coordinates. Design a separate AOI-only stable-reference estimator, backed by independent stable-ground evidence and alternate-reference sensitivity. Preserve the Known Place target-buffer implementation without alteration.

### P1 — field/benchmark validation
Use independent known displacement, event-footprint, glacier feature tracking or GNSS/control data where available, plus spatially correlated nulls. Report precision/recall, false-candidate density and detection probability with held-out AOIs. Software tests are not physical validation.

## External references

- ASF [GOFF guide](https://nisar-docs.asf.alaska.edu/goff/): geocoded 80 m pairwise offsets; product layer spacing/window/search vary with bandwidth/area and offsets are supplied unfiltered, so outliers are expected.
- ASF [GUNW guide](https://nisar-docs.asf.alaska.edu/gunw/): 80 m unwrapped phase with coherence/components and ionosphere screen; screen not applied by default; available external phase corrections including troposphere are not removed by default.
- Kääb & Wouters (2022), [correlation dispersion and glacier displacement uncertainty](https://tc.copernicus.org/articles/16/2285/2022/index.html): measurement precision is spatially heterogeneous and correlation-peak properties can support pixel-level uncertainty.
- Berardino et al. (2002), [SBAS InSAR](https://doi.org/10.1109/TGRS.2002.803792): compatible small-baseline network, SVD linking and use of spatial/temporal information to handle atmospheric phase effects.
- Wright et al. (2004), [3-D InSAR geometry](https://doi.org/10.1029/2003GL018827): one interferogram measures LOS only; near-polar look geometry has weak north-component resolution.
- Fukuzono (1985), [inverse velocity method](https://doi.org/10.3313/jls1964.22.2_8): conditional acceleration model, not target-free AOI discovery.

**Evidence scope:** static source trace and repository test review. No new raw NISAR granules were downloaded and no new live AOI was processed for this documentation audit.
